# Mobile Navigation

An example implementation of an accessible, responsive navigation bar. This repository serves a place of learning, sharing, and keeping up-to-date with modern standards when implementing navigation that is both mobile-friendly and accessible.

## AI Usage

AI was used only to generate the following assets:

- `logo.full.png`
  - Note: `logo.png` is manually-resized and cropped version of the original asset
- `favicon.svg`

AI was _not_ used to generate any code within this repository.
